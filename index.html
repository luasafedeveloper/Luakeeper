AST Compiler & VM Architecture

1. Luau AST Parser Engine

Parses raw Luau source code into structured lexical tokens, identifying local declarations, assignments, and function calls dynamically.

2. Polymorphic Custom ISA

Translates AST nodes into custom virtual opcodes (OP_LOADK, OP_GETGLOBAL, OP_SETGLOBAL, OP_CALL, OP_ADD, OP_RET) with randomized bytecode assignments per compile session.

3. Rolling-Key Cipher & Constant Scattering

Constants are fragmented and encoded with bitwise XOR masks, while the execution stream requires rolling key progression.
