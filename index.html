Protection Architecture Overview

1. Dynamic Custom ISA

Transforms standard Luau opcodes into a specialized hybrid register-stack virtual instruction set. Instruction mappings change dynamically per compilation batch.

2. Control Flow Flattening & Opaque Predicates

Removes native structured loops/branches, restructuring the execution into a single state machine driven by dynamic state variables and randomized trap branches.

3. Rolling-Key Bytecode Encryption

Bytecodes are encrypted sequentially using an evolving mathematical key state. Extracting a static slice of bytecode is insufficient without computing the prior key progression.

4. Anti-Hooking & Metatable Sandboxing

Detects environment inspection attempts (e.g., `debug.getupvalue`, `hookfunction`, `getfenv`). Trapping metatables force execution into defensive loops if unauthorized reflective queries are executed.
